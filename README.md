## 💼 Client Work

### 🏗️ [Artex – Real Estate Development Platform](https://artex-workspace.vercel.app/)
*A full website and content management system for a construction and real estate developer in Batumi.*
- **Highlights:** Full-screen hero video, detailed project pages (Artex Parkline, Artex Premier, Gate by Artex) with specs, galleries and apartment listings, news portal with category filters, team and services carousels, FAQ and consultation forms.
- **Under the hood:** Content managed through a custom **Sanity Studio** admin panel, three languages (GE / EN / RU), prerendered pages for SEO, route-level code splitting, WebP image optimization, and automatic deployment via **GitHub Actions → Vercel**.
- **Tech:** React 19, Vite, Tailwind CSS v4, Sanity, React Router, Embla Carousel, Vercel.

### ⚓ [Prime Marine – Maritime Agency & Freight Forwarding](https://primemarine.vercel.app/)
*A complete rebuild of the website for a ship agency and freight forwarding company operating in the ports of Batumi and Poti.*
- **Highlights:** Services, ports and cargo gallery pages, a news archive with 30+ articles migrated from the old site, team page, and a quote request form backed by a serverless API.
- **Under the hood:** Content managed in **Sanity** with every field localized (GE / EN / RU), build-time content fetching, prerendering with Puppeteer, generated sitemap and SEO files, redirects preserving old URLs, and a mobile-first reusable UI component system.
- **Tech:** React 19, Vite, Tailwind CSS v4, Sanity, Vercel Serverless Functions, Lucide.

### 📸 [Elisabeths – Photography Studio Platform](https://elisabeths.vercel.app/)
*A premium digital portfolio for a professional photographer.*
- **Highlights:** Dynamic image galleries, modern minimalist design, and seamless navigation.
- **Tech:** React, Tailwind CSS, Framer Motion.
